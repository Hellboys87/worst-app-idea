A one-sentence pitch for the worst, most useless app imaginable — an alarm clock you have to apply to use — written by a tiny Node program for make.fun's "The Worst App Idea Ever Pitched" bounty.

## Run it

```sh
node main.ts
```

This writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
